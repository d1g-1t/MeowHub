# MeowHub

MeowHub — современная соцсеть для кошатников, объединяющая API, фронтенд и инфраструктуру для обмена историями о пушистых друзьях.

## Стек и ключевые решения

- **Backend:** Django 4.2, Django REST Framework, Djoser, PostgreSQL, Redis, Celery-ready кэш-слой через `django-redis`, Gunicorn.
- **Frontend:** React + Vite UI (CRA-совместимые компоненты), Nginx для прод-статик.
- **DevOps:** Docker/Compose, Makefile-обёртки и uv для управления зависимостями.
- **Функциональные акценты:**
	- Кэширование списков котов с TTL и инвалидацией при CRUD-операциях (`cats/cache.py`).
	- Оптимизированные ORM-запросы, кастомные менеджеры, валидация цветов и изображений.
	- Логи и пользовательские сообщения строго на русском языке.
	- Отдельные окружения для API, фронтенда, PostgreSQL и Redis.

## Структура репозитория

```
meowhub/
├── backend/                # Django + DRF (приложение cats, проект meowhub_backend)
├── frontend/               # React-клиент, собирается в Docker и отдаётся Nginx
├── infra/                  # gunicorn unit-файл, nginx конфиг и deploy info
├── docker-compose.yml      # Оркестрация api/frontend/db/redis
├── Makefile                # Удобные цели для Docker-команд
├── pyproject.toml          # Управление зависимостями через uv
└── .env.example            # Шаблон переменных окружения
```

## Подготовка окружения

1. Установите **Docker** (Desktop) и **uv** (`pip install uv` или бинарь с https://github.com/astral-sh/uv).
2. Скопируйте переменные окружения и адаптируйте под себя:

	 ```bash
	 cp .env.example .env
	 ```

	 Минимально важно указать `DJANGO_SECRET_KEY`, список `DJANGO_ALLOWED_HOSTS` и доступы к БД при необходимости.

## Быстрый старт через Docker + Makefile

| Команда              | Что делает                                                             |
| -------------------- | ---------------------------------------------------------------------- |
| `make setup`         | Полная сборка после клонирования: создаёт `.env`, собирает образы, поднимает сервисы в фоне и применяет миграции. |
| `make up`            | Собирает образы и поднимает `api`, `frontend`, `db`, `redis` в фоне (требует готовый `.env`). |
| `make down`          | Останавливает и удаляет контейнеры/сети/volumes (без потери данных Postgres). |
| `make build`         | Пересобирает все сервисы.                                              |
| `make migrate`       | Запускает `python manage.py migrate` внутри контейнера API.            |
| `make collectstatic` | Собирает статику Django.                                               |
| `make createsuperuser` | Создаёт суперпользователя через `uv run`.                            |
| `make shell`         | Открывает Django shell внутри контейнера API.                          |
| `make test`          | Запускает Django тесты.                                                |

После `make setup` приложения доступны по адресам:

- API: http://localhost:8000/api/
- Админка: http://localhost:8000/admin/
- Фронтенд: http://localhost:3000/

### Тестовая учётная запись

Чтобы зайти в систему на фронтенде (http://localhost:3000/), используйте автоматически созданного пользователя:

- **Логин:** `meowhub_demo`
- **Пароль:** `meowhub123`

Учётные данные настраиваются переменными `DJANGO_TEST_USER_USERNAME`, `DJANGO_TEST_USER_EMAIL` и `DJANGO_TEST_USER_PASSWORD` в `.env`.

### Демонстрационные данные

- После миграций приложение автоматически наполняется 25+ котами, владельцами и достижениями.
- Все демонстрационные владельцы используют пароль из `DJANGO_TEST_USER_PASSWORD`, поэтому их удобно показывать в интерфейсе.
- Чтобы отключить автозагрузку данных (например, на проде), установите `DEMO_DATA_ENABLED=False` перед запуском миграций.

## Локальный запуск backend без Docker

Используйте uv, чтобы повторить продовую среду:

```bash
uv sync
uv run python manage.py migrate
uv run python manage.py runserver 0.0.0.0:8000
```

Настройте переменные окружения аналогично `.env` (можно через `django-environ`). Redis и PostgreSQL должны быть доступны по адресам, указанным в `DJANGO_DATABASE_URL` и `REDIS_URL`.

## Дополнительные заметки

- **Логирование:** все сообщения (в том числе кастомные исключения) находятся на русском языке и проходят через стандартный конфиг Django.
- **Кэширование:** настройте TTL через `CACHE_TTL` в `.env`. При создании/обновлении/удалении кота кэш соответствующей страницы очищается автоматически.
- **Развёртывание:** см. `infra/default`, `infra/gunicorn_meowhub.service` и `infra/meowhub_site.txt` — они используются для настройки systemd и nginx на сервере.
- **Фронтенд:** переменная `REACT_APP_API_URL` пробрасывается в Docker build аргумент (по умолчанию `/api`). Для standalone-сборки задайте нужный URL перед `npm run build`.

Готово — MeowHub запускается одной командой `make up` (которая автоматически применяет миграции), журналирует события по-русски и обслуживает контент котов с учётом кэширования и оптимизированных запросов. Удачной работы! 🐾
